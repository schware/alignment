# ADR-0002: 시작점을 기록한다 — 현재 스킬, 타임라인, 타겟 시장, 기존 포트폴리오

- **Status**: Partially Superseded by ADR-0005 (아래 스킬/타임라인 부분은
  Supersede됨 — 정정된 경력 타임라인은 ADR-0005 참고; 전환 목표 시점,
  시장, 기존 포트폴리오 없음이라는 사실은 아래 내용 그대로 유효)
- **Date**: 2026-09-06
- **Deciders**: 본인

## Context

이후의 모든 계획(ADR-0003 이후, `ROADMAP.md`)은 정직한 시작점에
의존한다. 이 baseline을 이 대화의 transcript 안에만 남겨두는 대신, 여기에
한 번 명확하게 기록해서 이후의 ADR들이 이걸 다시 서술하지 않고 고정된
지점으로 참조할 수 있게 한다 — 그리고 나중에 실제로 얼마나 나아갔는지
측정하기도 쉬워진다.

## Decision

2026-09-06 기준 baseline:

- **기존 언어/도메인 경험**: C, C++, C#, Java. 주요 업무는 서버 통신과
  POS(Point-of-Sale) Client 개발 — 즉 네트워크 프로토콜, client-server
  architecture, 프로덕션 client 소프트웨어에 대한 실전 경험은 있지만,
  cloud-native 툴체인, container orchestration, AI/ML 경험은 없음.
- **오늘 작업이 이 baseline 위에 이미 더한 것**: 동작하고, 테스트되고,
  ADR로 문서화된 Python monorepo(`sun-moon-python-platform`) — DDD로
  구조화된 서비스, 비동기 I/O(HTTP/TCP/Redis), 그리고(아직 실제 LLM은
  아니지만) 동작하는 AI Agent tool-calling 루프까지. 오늘 Claude와 함께
  처음 만든 새 영역이지, 아직 독립적으로 증명된 스킬은 아니다.
- **Timeline**: **2026년 4분기(Q4)경** 커리어 전환을 목표로 함 — 이 ADR
  날짜로부터 약 3.5개월. "전환 전에 포트폴리오/인터뷰 준비를 끝낸다"인지
  "전환 직후에도 계속 만들어간다"인지는 아직 정하지 않았다
  (ADR-0003/ROADMAP 참고) — 이 ADR은 종점만 고정할 뿐, 그때까지 뭐가
  갖춰져야 하는지는 정하지 않는다.
- **타겟 시장**: 제약 없음 — 국내/해외·리모트, 스타트업/대기업 전부 열려
  있음.
- **기존 포트폴리오**: 없음. `sun-moon-python-platform`(그리고 이 계획에
  따라 앞으로 더 만들 것들)이 사실상 이번 이직을 위해 처음부터 만드는
  포트폴리오 전부다.

## Alternatives considered

일반적인 의미로는 해당 없음 — 이 ADR은 선택지 중 고르는 게 아니라 사실
패턴을 기록하는 것이다. 그래도 ADR로 남기는 이유는(암묵적으로 남겨두지
않고), 이후의 모든 전략적 ADR이 이걸 암묵적 가정이 아니라 명시적이고
날짜 찍힌 것으로 전제하기 때문이다.

## Consequences

- 앞으로의 로드맵 항목 하나하나를 "이게 C/C++/C#/Java + 네트워크 프로토콜
  강점 위에 세워지는가, 아니면 아예 경험 없는 걸 새로 배워야 하는가"로
  점검해야 한다 — 둘 다 넣는 건 괜찮지만, 약 3.5개월(그리고 아마 아직
  풀타임 재직 중이라는 가용 시간)을 감안하면 그 비율이 현실적이어야 한다.
- 기존 포트폴리오가 없다는 건 "이미 있는 걸 다듬기만 하면 되는" 지름길이
  없다는 뜻이다 — 최종 포트폴리오 서사에 들어갈 모든 것이 이 기간 안에
  만들어져야 한다.
- 타겟 시장에 제약이 없으므로, 로드맵이 특정 지역/회사 규모의 채용
  트렌드에 과하게 맞춰지면 안 된다 — 시장을 가리지 않고 잘 통하는
  일반적인 엔지니어링 기본기와 명확한 문서화 쪽에 무게를 두는 게 낫다.
